# ⚾ 球場生態圈：機密情報局 (Baseball Roleplay Prompt Builder)

「球場生態圈：機密情報局」是一個結合了**沉浸式角色扮演**與**動態提示詞生成 (Prompt Builder)** 的互動式 Web 應用程式。

玩家將化身為棒球場中各種鮮為人知的「機密身分」（如：運動防護員、數據分析師、吉祥物等），透過一步步選擇「地點」、「對象」、「語氣」與「道具」，最終生成出極具戲劇張力且幽默的客製化機密情報！

### 🔗 [👉 點此體驗 Live Demo] https://kailin80.github.io/STP/

---

## ✨ 核心功能 (Features)

*   **🎭 豐富的角色系統**：內建 6 大職群、共 18 種獨特的球場職業。每個角色都有專屬的「武器」、「任務」與特殊的「動作選項」。
*   **🧩 互動式情境拼圖**：透過視覺化的色塊設計（藍、黃、綠、紅），引導玩家循序漸進地選擇情境元素，打造獨一無二的故事線。
*   **🧠 龐大的動態回應資料庫 (Custom Response DB)**：
    *   內建超過百種以上的預設劇情組合！
    *   根據玩家前幾輪的選擇（角色 + 對象 + 語氣 + 道具），系統會自動配對並輸出完全不同的專屬劇情（例如：變成機器人語氣、鬼故事語氣或熱血動漫風）。
*   **🔒 階段式解鎖機制**：隨著「回合 1」、「回合 2」的推進，系統會自動解鎖下一階段的選項面板（解開 🔒 圖示），增加遊戲的推進感與期待感。
*   **🎨 Neo-Brutalism 視覺風格**：採用強烈對比的邊框、粗體字與鮮豔的按鈕狀態切換，帶來年輕、活潑且極具現代感的遊戲化介面 (Gamification UI)。

---

## 🛠 技術棧 (Tech Stack)

本專案採用純前端技術開發，畫面排版採用 Tailwind CSS，邏輯處理完全依賴原生 JavaScript：
*   **HTML5**：應用程式的語意化骨架。
*   **Tailwind CSS (via CDN)**：快速建構響應式、Neo-Brutalism 風格的現代化 UI，不需撰寫繁瑣的 CSS。
*   **Vanilla JavaScript (ES6+)**：
    *   **狀態管理 (State Management)**：管理使用者的選擇狀態與當前遊戲回合。
    *   **資料篩選與比對邏輯**：負責在龐大的 `CUSTOM_RESPONSE_DB` 中精準比對玩家選擇的條件，動態渲染對應的回應。
    *   **DOM 操作**：動態生成按鈕、控制區塊解鎖動畫與聊天室自動滾動機制。

## 💡 如何擴充資料庫 (For Developers)

這個專案的核心在於 `CUSTOM_RESPONSE_DB`。如果你想新增新的劇情分支，只需在資料庫中加入新的條件物件即可。系統具備高度的擴展性：

```javascript
{
    "conditions": {
        "step1": {
            "role": "運動防護員",
            "location": "熱呼呼的紅土球場上",
            "target": "聽不懂地球語言的外星人",
            "tone": "神祕像講鬼故事的語氣"
        },
        "step2": {
            "tool": "急救冰敷袋與醫療剪刀",
            "action": "衝上場幫抽筋的球員冰敷"
        }
    },
    "round1": "第一回合的自訂回應...",
    "round2": "第二回合的自訂回應...",
    "step3_list": [
        {
            "format": "裡面必須大量使用 Emoji",
            "round3": "第三回合對應 Emoji 的最終產出..."
        },
        // ... 可針對不同的 format 設定不同的 round3 結局
    ]
}
